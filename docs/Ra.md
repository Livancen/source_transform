## 定稿：信息架构与规则

### 一级菜单（6 项）

```
图片 | 视频 | 比例裁剪 | 自定义裁剪 | 拼接 | 自定义拼接
```

| Tab | 列表过滤 | 处理范围 | 交互形态 |
| --- | --- | --- | --- |
| **图片** | 仅图片 | 仅列表内图片（可批量） | 选项 + 开始 |
| **视频** | 仅视频 | 仅列表内视频（可批量） | 选项 + 开始 |
| **比例裁剪** | 图+视频 | 批量，当前列表勾选文件 | 多比例 + 开始 |
| **自定义裁剪** | 选 1 个文件（图或视频） | **单文件**，绝对像素 | 内嵌预览框选 |
| **拼接** | 选 2 个（双图或双视频） | **固定 2 路**，不混图+视频 | 槽位布局工作台 |
| **自定义拼接** | 图+视频 | **最多 6 层**，可混排 | 自由画布工作台 |

原则：**图/视频批量互不混合**；裁剪/拼接为独立工作台；比例裁剪单独入口。

---

### 各 Tab 功能

#### 图片（批量）

压缩（质量 / 可选降分辨率）、单独改分辨率、转格式、旋转  
（区域裁剪不在此；比例裁剪走独立 Tab）

#### 视频（批量）

压缩、改分辨率、降码率、Profile/Level、H.265→H.264、H.264→H.265、转格式、旋转、静音、帧率  
（区域裁剪 / 拼接走独立 Tab）

#### 比例裁剪

- 图 + 视频，可批量
- 多比例输出
- **命名走自身规范**（不受设置页通用命名影响）

#### 自定义裁剪

- 每次 1 个文件（图或视频）
- 绝对像素坐标
- 下方内嵌预览（视频取帧 / 图片原图），不弹窗、不批量

#### 拼接

- 双视频 **或** 双图片（不混排、不 3 路）
- 上下 / 左右
- 槽位比例预设 + fill 拉伸
- 可选最终输出宽高
- **视频输出**（`MergeWorkspace` → `merge_videos`）：
  - 帧率：**30 / 60**（默认 30）；选 60 且源不足时用 FFmpeg `fps` **补帧**（重复帧）
  - 可选 Profile（baseline/main/high）+ Level（3.0～5.2）
  - 无音轨；`libx264` + `yuv420p`；时长 `shortest=1`

#### 自定义拼接

- 自由画布，最多 **6** 图层（`JoinWorkspace` → `join_media`）
- 图片与视频 **可混排**
- 输出类型规则：
  - 全图 → `png`
  - 含任意视频 → `mp4`
- 画布预设 / 自定义尺寸；背景黑 / 白（纯图可透明）
- 拖拽、缩放、层级、填充（cover / contain / fill）
- **边缘吸附**（可开关）：画布边 + 其它素材边/中线
- **视频输出** 与拼接相同：帧率 30/60（可补帧）、可选 Profile/Level、无音轨
- 时长：overlay `shortest=1`；静图 `-loop 1` 铺满

### 输出与命名（设置页）

| 规则 | 说明 |
| --- | --- |
| 输出目录 | 设置中配置（沿用现有 input/output） |
| 通用命名 | 可选拼接：①原名 ②时间戳 ③标准时间 ④自定义文本 |
| 生效范围 | **除比例裁剪外** 全部模式（含拼接 / 自定义拼接） |
| 比例裁剪 | 继续专用命名：`原名-比例(比值)-(范围)-(日期).ext` |

---

### 必须遵守的约束（实现时）

1. Tab 切换 → 列表只显示当前类型（比例裁剪、自定义裁剪/拼接/自定义拼接列表可为全量，工作台内再筛）
2. 开始/导出只处理**当前列表勾选（或当前工作台选中）**
3. 图片 Tab 与视频 Tab **不能**一次混合处理
4. 自定义裁剪：单文件 + 像素框
5. 拼接：2 路同类；自定义拼接：≤6 层，可混排
6. 视频批量 **无** 区域裁剪入口
7. 拼接类视频输出默认无音轨；帧率仅 30/60 两档（不足则补帧）

| Tab | 按钮 |
| --- | --- |
| 图片 | `开始处理图片 (N)` |
| 视频 | `开始处理视频 (N)` |
| 比例裁剪 | `按比例裁剪 (N×比例数)` |

| 自定义拼接 | `导出拼接`（工作台内） |

### 视频编码约定（拼接 / 自定义拼接）

| 参数 | 行为 |
| --- | --- |
| 编码器 | `libx264` |
| 像素格式 | `yuv420p` |
| 音频 | 去除（`-an`） |
| 帧率 | 用户选 30 或 60；滤镜 `fps=N` + 输出 `-r N`；升帧为重复帧补帧 |
| Profile/Level | 默认不指定（x264 自选）；勾选后写入 `-profile:v` / `-level:v` |
| 自定义拼接额外 | `+faststart`；底图 `color` 与图层 `overlay` |
